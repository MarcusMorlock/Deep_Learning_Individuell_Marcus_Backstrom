# Deep Learning – Klassificering av ansiktsuttryck  
Marcus Bäckström

Detta projekt är min lösning på den individuella inlämningsuppgiften i Deep Learning.  
Notebooken innehåller hela flödet: dataladdning, preprocessing, modellbygge, träning, utvärdering, prediktion och analys.

## Hur du kör projektet
1. Installera Python 3.13.7  
2. Skapa och aktivera en virtuell miljö  
3. Installera beroenden: pip install -r requirements.txt
4. Lägg in datasetet **FER-2013** i mappen `Data/` så att strukturen ser ut så här:
Data/
  train/
  test/
5. Öppna notebooken: Report_Marcus_Bäckström.ipynb
6. Kör alla celler uppifrån och ned.
